# J873g / T8152 AGX bring-up

## Current checkpoint — 2026-10-15

See the [current development checkpoint](checkpoints/2026-10-15/README.md)
for source patches, candidate-specific hardware results and remaining
conformance work. The notes below describe the earlier bring-up state.

The `j873` branch was created on 2026-09-22 from the published Mesa `j813`
commit `658dee6c3c2df664d7e7598e3bfc989fdd6d3a39`. It subsequently merged
the newer `j813` tip `7fbab581d3bc` and carries its AGX3 compiler, Gallium,
and Vulkan sources unchanged.

Apple's J873g restore device tree identifies the M6 Mac mini as `J873gAP`,
`Mac18,5`, and `T8152`, with a `gpu,t8152` node. This is platform identity,
not evidence that its GPU uses the M5 `G17G` instruction set, firmware ABI,
command stream, or Mesa device parameters. The J813 code must stay gated to
the GPU and kernel interfaces it has actually been validated against.

Before enabling a J873 driver path, record the T8152 GPU generation and
firmware interface from target evidence, add a matching kernel DRM path and
UAPI, then validate shader encoding, resource layout, rendering, and recovery
on the target. This branch has no J873 GPU execution or conformance result.

The paired source is the `j873` branch of `aurora-silicon/linux-aurora`.
Firmware and board evidence is recorded in the sibling J873 workbench at
`AuroraSilicon/targets/j873/`.

## GPU evidence — 2026-09-23

The exact 26A428 mac18g kernel identifies `AGXAcceleratorG18G`,
`AGXG18GDevice`, `AGXGartG18G`, and `AGXFirmwareKextG18GRTBuddy`.
The restore IPSW supplies `Firmware/agx/armfw_g18g.im4p` and
`Firmware/agx/armfw1_g18g.im4p`. Their FTAB entries (`a000`/`b000` and
`a010`/`b010`) contain ARM64 Mach-O images with
`RTKit_release-3514.0.15.release` and G18 startup labels. This establishes
G18G firmware identity, not G17 ISA or command-stream compatibility.

The HV experiment has reached and answered the six early UAT information
queries using empty private tables. Live ADT geometry is mode 1 with a
43-bit GPU VA; no inherited GPU table or GPU DMA has been enabled by that
experiment. The checked inventory and exact M6 ABI findings live in
`experiments/j873/hv/G18G-BOOTSTRAP.md` on the m1n1-aurora `j873` branch.

Next runtime requirements remain the Apple GPU initialization trace, native
Linux DRM submission/recovery, and target shader/render validation. The
visible framebuffer Xfce desktop does not establish Gallium acceleration.
