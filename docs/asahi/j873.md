# J873g / T8152 AGX bring-up

The `j873` branch was created on 2026-09-22 from the published Mesa `j813`
commit `658dee6c3c2df664d7e7598e3bfc989fdd6d3a39`. It subsequently merged
the newer `j813` tip `7fbab581d3bc` and carries its AGX3 compiler, Gallium,
and Vulkan sources unchanged.

Apple's J873g restore device tree identifies the M6 Mac mini as `J873gAP`,
`Mac18,5`, and `T8152`, with a `gpu,t8152` node. This is platform identity,
not evidence that its GPU uses the M5 `G17G` instruction set, firmware ABI,
command stream, or Mesa device parameters. The J813 code must stay gated to
the GPU and kernel interfaces it has actually been validated against.

Before enabling a J873 driver path, record the T8152 GPU generation and
firmware interface from target evidence, add a matching kernel DRM path and
UAPI, then validate shader encoding, resource layout, rendering, and recovery
on the target. This branch has no J873 GPU execution or conformance result.

The paired source is the `j873` branch of `aurora-silicon/linux-aurora`.
Firmware and board evidence is recorded in the sibling J873 workbench at
`AuroraSilicon/targets/j873/`.
